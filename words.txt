# Nouns: the plural is generated. Override with  | pl=...
#     cactus | pl=cacti

# Verbs: list the frames the verb can fill after a colon:
#     vt    takes an object             (The goat ate the hat.)
#     vi    no object                   (The goat sneezed.)
#     vc    takes a that-clause         (She thinks that ...)
#     vpsy  takes a clausal subject     (That Mo is purple annoys the goat.)
#   Forms are generated. Override any of 3sg, past, prog:
#     hiccup: vi | past=hiccuped prog=hiccuping
#
# Guidelines: concrete, countable, a bit silly, classroom-safe. Intransitive
# verbs must sound complete on their own ("The goat sneezed.").
